# 小微财报 MVP

一个原生微信小程序财务月报 MVP，面向小微企业老板和兼职会计。

## 当前功能

- 企业初始化与资料维护
- 月份切换和月报状态管理
- 资产、负债、所有者权益填报
- 收入、成本、费用填报
- 金额按整数分计算，避免浮点误差
- 资产负债平衡校验
- 财务风险和异常提示
- 月报草稿、确认和撤销确认
- 资产负债表
- 利润表
- 毛利率、净利率、资产负债率、流动比率
- 近六个月收入与利润趋势
- 演示数据生成
- JSON 数据备份复制

## 页面结构

- `pages/index`：经营首页
- `pages/add`：月报填报
- `pages/stats`：财务报表
- `pages/profile`：企业和数据管理
- `pages/setup`：企业初始化

## 数据层

- `utils/report.js`：字段定义、金额计算、报表计算和校验
- `utils/store.js`：本地数据仓库、月报状态和演示数据

当前版本使用微信本地 Storage，适合产品验证。正式商用需要将 `utils/store.js` 替换成云端 Repository/API，并增加：

- 企业级数据隔离
- 微信身份与成员权限
- 云数据库和自动备份
- Excel 导入
- 服务端 PDF/Excel 导出
- 审计日志
- 敏感数据加密

## 本地检查

```bash
node tests/report.test.js
```

使用微信开发者工具打开项目即可运行。首次进入会跳转到企业初始化页面；也可以在“我的”页面加载六个月演示数据。
